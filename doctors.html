Abstract — This is motivated by the Courier Mail article. The disclosures of doctors are available on this Medicines Australia site. The search criterion used was state:“Queenland”. The analysis was performed by importing the csv file into Mathematica and utilized the Tabular framework.

Data

There were 7562 events with 12 fields. This represented 2653 doctors. The span of time was over 6.4 years (2019-2025). There 3 categories of monetary benefit to doctors:

  • meeting registration

  • travel

  • speaker fee for servivr

In the following these benefits were totalled. The following show amount by doctor, histogram of overall amounts and top 10 doctors. The subseqiquent plots of number of occasions of benefit and absolute number of occasions of benefit.

Mathematica Code used

I post this only for transparency. I have not commented the code.

i = Import["d:/mathematica/doctor.csv"];
d = i[[2 ;;, {3, -4, -3, -2}]];
f[u_] := ToExpression[StringDrop[StringReplace[u, "," -> ""], 1]]
money = {#1, f[#2], f[#3], f[#4]} & @@@ d;
m = ToTabular[money, 
   "Rows", <|"ColumnKeys" -> {"doctor", "reg", "travel", "ffs"}|>];
mon = TransformColumns[m, "money" -> Function[#reg + #travel + #ffs]];
doctor = 
 SortBy[AggregateRows[mon, "total" -> Function[Total[#money]], 
   "doctor"], Function[-#total]]
BarChart[doctor -> "total", 
 PlotLabel -> " Doctor Benefits ($)by doctor", BarOrigin -> Left, 
 Frame -> True, FrameLabel -> {None, "Benefit (dollars)"}]
 BarChart[doctor[[1 ;; 10]] -> {"doctor", "total"}, BarOrigin -> Left, 
 Frame -> True, 
 FrameLabel -> {None, "Benefit (dollars)", 
   PlotLabel -> "Top 10 Beneficiaries"}]

Histogram[doctor -> "total", Frame -> True, 
 FrameLabel -> {"Benefit (dollars)", "Count"}]

ecdf = EmpiricalDistribution[Normal@doctor[[All, 2]]];
g = Grid[
  Table[{Row[{"Percent of doctors benefit >", j, " dollars"}], 
    100 Probability[z > j, z \[Distributed] ecdf]}, {j, 
    PowerRange[10, 100000, 10]}],
  Alignment -> {Left, Right}, Frame -> All]
times = Sort[DateList[{#, {"Month", "Year"}}] & /@ i[[2 ;;, 2]]];
dur = DateDifference[times[[1]], times[[-1]], "Years"]
Length[times]
use = SortBy[
  AggregateRows[TransformColumns[mon, "count" -> (1 &)], 
   "Occasions" -> Function[Total[#count]/dur], "doctor"], 
  Function[-#Occasions]]
BarChart[use -> "Occasions"]
Histogram[use -> "Occasions", 
 PlotLabel -> "Distribution of Occasions/year"]
BarChart[use[[1 ;; 10, 2]], BarOrigin -> Left, Frame -> True, 
 FrameLabel -> {None, "Occasions per year"}]
 occ = SortBy[
  AggregateRows[TransformColumns[mon, "count" -> (1 &)], 
   "Occasions" -> Function[Total[#count]], "doctor"], 
  Function[-#Occasions]]
BarChart[occ[[1 ;; 10, 2]], BarOrigin -> Left, Frame -> True, 
 FrameLabel -> {None, "Top 10 Occasions per doctor"}]
BarChart[Sort[Counts[i[[2 ;;, 1]]]], BarOrigin -> Left, 
 ChartLabels -> Automatic]
